# Landing Page Media Files

This folder contains media files for the landing page sections.

## File Structure:
```
landing-page/
├── 1v1-battles.jpg          # Static image for 1v1 coding battles section
├── practice-skills.gif       # GIF for practice skills section  
├── track-progress.jpg        # Static image for track progress section
└── leaderboard.gif          # GIF for leaderboard section
```

## Recommended Image Specifications:
- **Static Images (JPG/PNG)**: 16:9 aspect ratio, 1200x675px minimum
- **GIFs**: 16:9 aspect ratio, optimized for web (under 5MB)
- **Format**: JPG for photos, PNG for graphics, GIF for animations

## Usage:
Images are referenced in the landing page as:
- `/images/landing-page/1v1-battles.jpg`
- `/images/landing-page/practice-skills.gif`
- `/images/landing-page/track-progress.jpg`
- `/images/landing-page/leaderboard.gif`
